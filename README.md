Project Objective
The objective of this project is to develop and compare machine learning models for predicting whether a breast tumor is benign or malignant using diagnostic measurements extracted from digitized images of fine needle aspirate (FNA) of breast masses.

Models Implemented
Logistic Regression
Random Forest
Neural Network
Best Results
Model	Accuracy	ROC-AUC
Logistic Regression	97.67%	99.88%
Random Forest	98.84%	99.77%
Neural Network	96.51%	99.77%
